# Diglot Weave Reader

An EPUB reader that weaves French or Middle Egyptian words into English text, so you
learn them from the sentence around them. Everything stays on your device.

**Open it:** https://ansonlai.github.io/diglot/

This repository only holds the published site. The `gh-pages` branch is replaced on
every release. Credits and licences for the word packs are in the app (Library →
Credits & licences) and in each pack's `ATTRIBUTION.txt`.
